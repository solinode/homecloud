HomeCloud

your own AWS, on your hardware.

github docs discord linkedin

HomeCloud is an open-source, self-hosted cloud. One binary runs thirty AWS-style services on Docker, with a web console, a CLI and an API. Your data never leaves your machines, and there's no bill.

install

curl -fsSL https://homecloud.drk1rd.systems/scripts/install.sh | sh
homecloud serve          # console on http://127.0.0.1:8080

Windows: irm https://homecloud.drk1rd.systems/scripts/install.ps1 | iex · needs Docker (or OrbStack / Docker Desktop)

speaks aws

The AWS CLI, the SDKs and Terraform work unchanged, with IAM enforced:

eval "$(homecloud aws-env)"
aws s3 cp photo.jpg s3://family/
aws lambda invoke --function-name resize out.json
terraform apply

services

  • compute EC2, EBS, Auto Scaling, EFS, ECS, ECR
  • storage & data S3, RDS (Postgres, MySQL, MariaDB, Redis, MongoDB), DynamoDB
  • serverless Lambda, API Gateway, Step Functions, EventBridge
  • messaging SQS, SNS
  • networking VPC, load balancers, Route 53, ACM
  • security IAM & STS, Cognito, KMS, Secrets Manager, Parameter Store
  • operations CloudWatch metrics, logs & alarms, CloudTrail, CloudFormation
