Why HomeCloud

The cloud you already know, running where you want it.

Everything you build against HomeCloud uses the same APIs, tools and mental model as AWS, without the account, the region or the invoice.

Speaks AWS

The AWS CLI, boto3, the JS/Go/Java SDKs and Terraform connect with a HomeCloud access key. Signatures, errors and ARNs match AWS.

One binary

A single homecloud file runs the API, the console and every service on Docker. Install in a minute on Linux, macOS or Windows.

IAM everywhere

Users, roles, policies with conditions and temporary credentials guard every request. Functions and instances get role credentials automatically.

A real console

A web console modeled on the one you know, with pages for every service, dark mode, and a browser shell into instances.

Built to keep running

Install it as a system service, back up state and volumes with one command, and upgrade in place with verified releases.

Yours, fully

Open source under AGPL-3.0. No telemetry in the product, no lock-in, and it works offline on your LAN or over Tailscale.

Drop-in

Point your code at HomeCloud. That's the migration.

  • Same SDK calls. Set AWS_ENDPOINT_URL and your boto3 or JavaScript code runs unchanged.
  • Same Terraform. Plans apply, re-plan clean and destroy for IAM, VPC, EC2 and S3.
  • Same patterns. DynamoDB streams trigger Lambda, which sends to SQS with its role's credentials.
app.py
import boto3

# AWS_ENDPOINT_URL=http://homelab:8080
table = boto3.resource("dynamodb").Table("orders")
table.put_item(Item={"pk": "order-1", "total": 42})

sqs = boto3.client("sqs")
url = sqs.get_queue_url(QueueName="jobs")["QueueUrl"]
sqs.send_message(QueueUrl=url, MessageBody="resize")
Get started

Up and running in three commands.

You need Docker: Docker Engine on Linux, or Docker Desktop / OrbStack on macOS and Windows.

Install

Download the binary for your platform.

curl -fsSL …/install.sh | sh

Serve

Start the API and console, and note the root password.

homecloud serve

Build

Use the console, the CLI or your AWS tools.

eval "$(homecloud aws-env)"
aws s3 mb s3://photos
